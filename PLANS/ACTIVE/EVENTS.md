# Мероприятия: доступ к записям

## Модель

У каждого видео (конференция и класс) есть мероприятие.
Человек видит и смотрит файл, только если:

1. файл опубликован (`isPublic`);
2. есть ACTIVE `UserEventAccess` именно на это мероприятие;
3. срок доступа по формуле `computeAccessUntil(paymentDate, event.startDate, accessDays)` ещё не истёк.

Staff (MODERATOR / ADMIN / SUPER) видит всё, в том числе скрытое.

`accessUntil` на пользователе — максимум по всем оплатам (вход на `/watch-conf`, `/watch-class`, живой эфир). Список и стрим файла проверяют конкретное мероприятие.

Повторный grant на то же событие обновляет ту же строку (`@@unique([userId, eventId])`).

## Сделано

1. Загрузка с обязательным `eventId` (конференция и класс) на `/admin/upload`.
2. Список, стрим и страница просмотра — по оплаченному мероприятию.
3. Админка: смена мероприятия у файла, история оплат в таблице пользователей, отзыв одной оплаты.

Старые файлы без `eventId` привязаны миграцией к ближайшему мероприятию. Без мероприятия обычный пользователь файл не видит.
