# Мероприятия и оплаты — хвосты

Ядро уже в проде: схема Event / UserEventAccess, `recalculateAccessUntil`, админка `/admin/events`, выдача и отзыв оплаты, колонка «последнее мероприятие».

Доступ к архиву сейчас проверяет общий `accessUntil` (любая активная оплата), а не оплату конкретного мероприятия.

## Осталось

1. **Загрузка видео с `eventId`**  
   На `/upload` выбрать мероприятие, upload-service писать `ConferenceFile.eventId`. Сейчас поле в БД есть, при загрузке не заполняется.

2. **Доступ к файлу по мероприятию**  
   Смотреть видео, только если есть ACTIVE `UserEventAccess` на `file.eventId` и срок не истёк. Staff — без ограничений. Сейчас достаточно любой живой подписки.

3. **История оплат в таблице пользователей**  
   Кнопка «История» со списком grant/revoke. Сейчас видно только последнее мероприятие.

Повторные оплаты одного события сознательно не делаем: `@@unique([userId, eventId])` остаётся, повторный grant обновляет ту же запись.
